# C# Module 4 — Exam: Telegram Bot

Exam project: a Telegram bot written in C#.

## What's inside

- `ExamTelegramBot_Project` — the bot (receives messages and replies, sends files with `InputOnlineFile`)

## Tech

C# · .NET · Telegram Bot API

## Run

Requires the .NET SDK.

```bash
cd src/ExamTelegramBot_Project/ExamTelegramBot_Project
# put your own bot token in the code or configuration first
dotnet run
```
